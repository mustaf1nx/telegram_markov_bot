# Telegram-бот с марковскими приветствиями

Бот встречает каждого нового участника группы или супергруппы уникальной
фразой, построенной цепью Маркова, и напоминает прочитать правила в описании и
гайд. На обычную переписку группы бот не отвечает.

> Telegram не отправляет ботам событие о новой подписке на обычный канал.
> Поэтому бот работает в группе/супергруппе либо в группе обсуждений,
> привязанной к каналу.

## Установка

Нужен Python 3.10 или новее.

```powershell
cd telegram_markov_bot
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

1. Откройте [@BotFather](https://t.me/BotFather), выполните `/newbot` и получите
   токен.
2. Вставьте токен в `.env` вместо примера.
3. Добавьте бота в группу. Отключать `Group Privacy` не требуется: события о
   новых участниках бот получает независимо от этого режима.
4. У бота должно быть право отправлять сообщения.
5. Запустите:

```powershell
python bot.py
```

После добавления бот сразу пишет `Бот подключён`. Если процесс бота в этот
момент не запущен, Telegram-сообщения обрабатываться не будут.

Команды:

- `/ops` — показать список всех ОП, Школ и назначенных администраторов;
- `/setopadmin <КОД_ОП> <@username>` — назначить администратора для ОП (доступно администраторам);
- `/preview` — тестовая генерация приветствия;
- `/allowpm` — выполнить в группе от имени администратора, чтобы открыть личные
  сообщения с ботом;
- `/id` — показать ID пользователя и текущего чата;
- `/start` — краткая справка.

Бот автоматически реагирует на упоминания Образовательных Программ (ОП) в сообщениях (как по коду: SE, BDA, CS и т.д., так и по полному названию: Software Engineering, Big Data Analysis и т.д.) и присылает карточку ОП с тегом соответствующего администратора. На обычные сообщения без упоминания ОП бот не отвечает.

Привязки ОП и администраторов хранятся в `op_admins.json`.


## Настройка генератора

Добавляйте приветствия в `greetings.txt`, по одной фразе на строку, затем
перезапускайте бота. Строки, начинающиеся с `#`, считаются комментариями.

- `MARKOV_ORDER=1` даёт больше разнообразия, но менее связный текст.
- `MARKOV_ORDER=2` — рекомендуемый баланс.
- `MARKOV_ORDER=3` даёт более связный текст, но чаще повторяет исходные фразы.
- `MAX_GREETING_WORDS` ограничивает длину результата.

## Docker

Файл `.env` должен содержать действующий `TELEGRAM_BOT_TOKEN`. Токен не
копируется внутрь образа, а передаётся контейнеру только при запуске.

Сборка и запуск в фоне:

```powershell
docker compose up --build -d
docker compose logs -f bot
```

Остановка:

```powershell
docker compose down
```

Разрешённые через `/allowpm` администраторы сохраняются в именованном volume
`bot-admins` и не исчезают при пересоздании контейнера. Обычные сообщения группы
бот игнорирует; он реагирует только на добавление новых участников и команды.

Для кратковременных сбоев подключения к Telegram установлен увеличенный таймаут
и автоматические повторы отправки приветствия через 1 и 2 секунды.
